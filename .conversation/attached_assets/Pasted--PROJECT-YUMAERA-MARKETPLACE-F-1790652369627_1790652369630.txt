🛠️ TEKNOLOGI
═══════════════════════════════════════════════════════════════
Backend:
- Node.js + Express.js
- MongoDB + Mongoose
- JWT + bcrypt (auth)
- Socket.IO (notif real-time + live chat)
- Multer + Cloudinary (upload gambar)
- Nodemailer (email notif)
- PDFKit + html2pdf (cetak struk PDF)
- Midtrans/Xendit (payment, mock dulu)
- QRCode (generate QR di struk)
- RajaOngkir API (ongkir otomatis)
- Helmet + CORS + express-rate-limit (security)

Frontend:
- HTML5 + Tailwind CSS (CDN)
- Vanilla JS + Alpine.js
- Socket.IO Client
- SweetAlert2 (popup notif)
- Lucide / Font Awesome Icons
- Chart.js (grafik dashboard)
- html2pdf.js (download struk)
- PWA (manifest + service worker)
- Web Push Notification (VAPID)

Deploy:
- Backend  : Railway / Render
- Frontend : Vercel / Netlify
- Database : MongoDB Atlas
- Upload   : Cloudinary
